## What
The Reports page runs all its numbers (attendance, time trends, payroll, shift notes) for a single start-date/end-date range you set at the top.

## Why
Every card, chart, and table on the page is calculated from the same range, so changing dates once updates everything together instead of each section needing its own filter.

## Where
Sidebar > Reports > the date fields at the top of the page.

## How
1. Open Reports. It defaults to the current week (Monday through today).
2. Set Start date and End date.
3. Click Refresh to recalculate everything for that range.

## What you'll see
Changing the report range resets any per-day job overrides you'd set in the Daily breakdown section - those only apply within the range they were set for.
