## What
Each session row on Timesheet Approvals has a delete action that permanently removes that employee's clock-in, clock-out, and any break events for that day.

## Why
For entries that were duplicated, test data, or added in error - a clean way to remove a whole session rather than editing individual clock events.

## Where
Sidebar > Timesheet Approvals > the delete icon on a session's row.

## How
1. Open Timesheet Approvals and find the session.
2. Click the delete action on that row.
3. A confirmation dialog appears: "Delete this session? This permanently removes [employee]'s clock in/out (and any break) for [date]. This can't be undone."
4. Confirm to delete permanently, or cancel to back out.

## What you'll see
This is a hard delete with no undo - the clock events themselves are removed, not just the approval status. If it fails, an error message shows in the confirmation dialog and nothing is deleted.
