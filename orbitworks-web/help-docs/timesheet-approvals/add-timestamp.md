## What
The Add Timestamp action on Timesheet Approvals lets you create a full clock-in/clock-out session for an employee by hand, including an optional break.

## Why
Covers cases where the normal clock-in kiosk or app wasn't available and an employee's hours never got recorded - this backfills the session so it shows up for approval like any other.

## Where
Sidebar > Timesheet Approvals > "Add Timestamp" button (top right of the table).

## How
1. Open Timesheet Approvals.
2. Click Add Timestamp.
3. Search and select the employee, set the date, clock-in time, and clock-out time.
4. Optionally check the break toggle and enter break minutes.
5. Enter a reason (required).
6. Submit. The session appears in the table for that date.

## What you'll see
Employee, clock-in time, clock-out time, and a reason are all required - the form blocks submission with "Employee, clock in, clock out, and a reason are required." if any are missing. The date can't be set earlier than the approvals cutover date (2026-09-06).
