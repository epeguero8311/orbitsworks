## What
The employee edit modal shows the employee's backup clock-in PIN and lets you edit it directly.

## Why
The PIN is a fallback way for an employee to clock in (via PIN entry) if face-match isn't working - admins need a way to look it up again or change it if it's been compromised or forgotten.

## Where
Sidebar > Employees > click the employee's row > the PIN field near the top of the modal.

## How
1. Open Employees and click the employee.
2. Find the PIN field and click the edit icon next to it.
3. Enter a new PIN.
4. Save.

## What you'll see
The PIN is shown in plain text in this modal (not masked) so it can be read off and given to the employee directly.
