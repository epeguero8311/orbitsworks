## What
The Jobs page lets you edit an existing job site's name and address in place.

## Why
Site names change, addresses get corrected, and typos happen - editing keeps existing clock events and assignments pointing at the same site record instead of creating a duplicate.

## Where
Sidebar > Jobs > Job Sites table > click the edit action on a site's row.

## How
1. Open Jobs.
2. Find the site in the Job Sites table and click to edit it.
3. Update the name and/or address.
4. Save. The row switches back to view mode with the new details.

## What you'll see
If you clear the name field entirely, saving is blocked with "Site name can't be empty." until you enter something.
